项目简介
本项目为个人在探索大语言模型（LLM）应用落地过程中的提示词工程（Prompt Engineering）实践记录。重点研究如何通过结构化指令（Structured Prompting）来提升模型输出的稳定性、准确性，以及如何为后续的 Agent 开发（Tool Calling）做前置准备。

核心涵盖内容
  Role-Task-Constraint (RTC) 结构**：边界控制，降低幻觉。
  Few-Shot 示例**：格式对齐，保证输出可解析。
  Chain-of-Thought (CoT) 思维链**：复杂逻辑拆解，提升准确率。
